# Remplay
### display youtube videos from discord on your screen
INSTRUCTIONS:
- Install every dependency in `main.py` (under LIBRARIES)
- Adjust preferences in each class (You must add TOKEN/CHANNELS under DiscordReader)
- Create a `vids` folder in the script's local directory

Then you can run `main.py` to start the bot and yeah,
> [!NOTE]
> Pygame code heavily taken from [pygame-autoplayer](https://github.com/kawediloru/pygame-autoplayer)
